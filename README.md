# GTA Texture Export

A Substance 3D Painter plugin that exports ready-to-use GTA V textures straight from a normal PBR (metallic / roughness) project. No more packing spec maps by hand or converting to DDS one file at a time.

For every texture set it writes:

| File | What it is |
|---|---|
| `<name>_d.dds` | **Diffuse**: base color, with opacity in alpha |
| `<name>_n.dds` | **Normal map**: DirectX or OpenGL |
| `<name>_s.dds` | **Specular**: GTA's RGB spec map, generated from metallic and roughness |

DDS compression is done by the NVIDIA Texture Tools Exporter. PNG and TGA output work without it.

---

## Features

- **One click for the whole project.** Every texture set is exported in a single pass.
- **Per-map control.** For each texture set, every map has its own tick box, file name and resolution.
- **Power-of-2 resolutions.** Choose any size from 128 to 8192 per map, or set them all at once.
- **Custom names.** Set a base name per texture set (`house_wall_brick` → `house_wall_brick_d`, `_n`, `_s`) or override any single file name.
- **Spec profiles.** Different GTA shaders need different spec values, so each texture set gets a profile: vehicle generic, vehicle paint, chrome, rubber, glass, or your own.
- **Live preview.** The profile editor shows the exact `_s` colour it will write for chrome, smooth and rough surfaces.
- **Chrome that looks like chrome.** Metal is darkened in the `_d`, the way GTA's own chrome is authored, with the shine coming from the `_s`.
- **Remembers everything.** Names, maps, resolutions and profiles are saved inside the `.spp`.

## How the `_s` map is built

GTA V uses an RGB specular map instead of PBR roughness / metallic:

| Channel | Meaning | Generated from |
|---|---|---|
| **R** | Specular intensity: how strong reflections are | roughness + metallic |
| **G** | Specular falloff: how sharp reflections are (1 = sharp) | roughness |
| **B** | Specular fresnel / reflection strength | metallic |

A profile controls how those values are mapped:

| Setting | Effect |
|---|---|
| Intensity (smooth / rough / metal) | R for smooth non-metal, rough non-metal and metal areas |
| Fresnel (non-metal / metal) | B for non-metal and metal areas |
| Falloff at roughness 0 / 1 | The G range; Rockstar's chrome sits around 0.75 |
| Falloff mapping | Linear (`1 - roughness`) or a Blinn-Phong exponent divided by the shader's falloff multiplier |
| Shader specIntensityMult | Divides R by this value; leave at 1 unless you need to compensate |

The built-in **Generic** profile turns smooth full metal into roughly `(199, 191, 237)`, matching Rockstar's own chrome spec maps.

The built-in profiles are starting points. Tune them against what you see in-game, then duplicate or rename them for your own shaders.

## Requirements

- **Adobe Substance 3D Painter** with Python plugin support. Versions using PySide2 and PySide6 both work.
- **NVIDIA Texture Tools Exporter (standalone)**, only needed for DDS output.
  Download: <https://developer.nvidia.com/texture-tools-exporter>
  Default path: `C:\Program Files\NVIDIA Corporation\NVIDIA Texture Tools\nvtt_export.exe` (can be changed in the panel)

## Installation

1. In Painter, open **Python → Plugins Folder**. An Explorer window opens.
2. Copy `gta_spec_export.py` into that folder.
3. In Painter, choose **Python → Reload Plugins Folder**.
4. Tick **gta_spec_export** in the Python menu.

The **GTA Texture Export** panel opens as a dock. If it's hidden, find it under **Window → Views**.

To update, replace the file, then untick and re-tick the plugin in the Python menu.

---

## Usage

1. **Pick texture sets.** Tick the ones to export in the table.
2. **Configure each set.** Click a texture set and, in the section below:
   - set the **Export name**,
   - choose a **Spec profile**,
   - tick the maps you want, and set a **resolution** and optional **custom file name** for each.
3. **Set the output.** Choose a folder, a file type and the formats.
4. Click **Export GTA textures.** The log shows every file written, with its size and format.

### Default DDS formats

| Map | Default | Other options |
|---|---|---|
| `_d` | Auto: DXT1, or DXT5 when the texture set has opacity | DXT1, DXT5, BC7, uncompressed |
| `_n` | DXT5 | DXT1, BC5 / ATI2, BC7, uncompressed |
| `_s` | DXT1 | DXT5, BC7, uncompressed |

Mipmaps are generated by default. Quality can be set from Fastest to Highest.

## Tips & troubleshooting

- **Bumps look inverted in-game?** Switch **Normal format** between DirectX and OpenGL.
- **Chrome looks black or plastic?** Use the Chrome or Generic profile, and keep **_d metal darkening** on.
- **"nvtt_export.exe not found"?** Point the **nvtt_export.exe** field at your install, or switch the file type to PNG / TGA.
- **"Two maps would be written as …"?** Two texture sets resolve to the same file name; give one of them a different export name.
- **Texture set skipped?** `_s` needs a roughness or metallic channel, and `_d` needs a Base Color channel.
- Check new exports in CodeWalker or OpenIV before relying on less common formats such as BC5 and BC7.

Custom profiles are stored next to the plugin in `gta_spec_export_profiles.json`. That file is ignored by git, so your personal tweaks stay local.
